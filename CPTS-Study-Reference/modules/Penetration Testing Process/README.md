# Penetration Testing Process

> Status: 🟨 In progress

## Overview
الموديول ده بيأسس للـ methodology العامة لأي اختبار اختراق: Pre-engagement, Information Gathering, Vulnerability Assessment, Exploitation, Post-Exploitation, Reporting. مش موديول تقني بقدر ما هو framework للتفكير والتوثيق.

## Key Concepts
- Rules of Engagement (RoE) والـ Scope بيتحددوا قبل أي خطوة
- الفرق بين Black-box / Grey-box / White-box
- أهمية التوثيق أول بأول مش في الآخر
- Pre-engagement, ROE, Communication plan

## Lab Notes / Walkthrough
- راجعت الفرق بين أنواع التقييمات (Pentest vs Red Team vs Vuln Assessment)
- عملت template بسيط لتوثيق كل مرحلة أثناء الممارسة على الـ labs

## Common Mistakes / Gotchas
- الدخول في الاستغلال بدون توثيق كافي للـ enumeration
- تجاوز الـ scope من غير تأكيد كتابي
