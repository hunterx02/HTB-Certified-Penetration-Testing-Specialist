## Overview

## Key Concepts
- Vulnerability Assessment بيركز على الاكتشاف والتصنيف مش الاستغلال
- Penetration Test بيثبت قابلية الاستغلال الفعلي
- أهمية تحديد الـ deliverables من البداية مع العميل
